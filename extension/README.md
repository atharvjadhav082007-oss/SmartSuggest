# 🔌 SmartSuggest Chrome & Edge Extension

Connects Gmail, Outlook, LinkedIn, and any web compose area directly to your local **C++ OOP Engine** (`app.exe --server` on port 8080).

---

## 🚀 How to Install in 30 Seconds

### Step 1: Open Chrome / Edge Extensions Page
- In **Google Chrome**, open: `chrome://extensions/`
- In **Microsoft Edge**, open: `edge://extensions/`

### Step 2: Enable Developer Mode
- Toggle the **Developer mode** switch in the top-right corner of the page.

### Step 3: Load the Extension
- Click the **"Load unpacked"** button in the top-left.
- Select the `extension` folder inside this project:
  ```
  d:\OOP UPDATE\oops cp\extension
  ```
- That's it! The **SmartSuggest Assistant** icon will now appear in your browser toolbar.

---

## 📧 How to Use in Gmail or Outlook

1. Make sure your C++ server is running:
   ```cmd
   app.exe --server
   ```
2. Open **[Gmail](https://mail.google.com)** or **[Outlook Web](https://outlook.office.com)** and click **Compose**.
3. Start typing your email draft.
4. You will see the floating **SmartSuggest** badge in the corner of your email:
   - 🟢 `✓ Clean text` when everything is grammatically correct.
   - 🟠 `⚡ X Issues` when typos or grammar mistakes are detected.
5. Click the badge to open the quick-fix list and click **"✦ Apply Corrections to Email"** to auto-fix the draft directly inside Gmail or Outlook!
